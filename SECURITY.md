| Version | Supported          |

## Reporting a Vulnerability

Security is a fundamental invariant across all repositories in the `@Sadique721` ecosystem.

If you discover a security vulnerability or credential leak:
1. **Do not open a public issue.**
2. Send a confidential report to [mdsadiqueamin721786@gmail.com](mailto:mdsadiqueamin721786@gmail.com).
3. Include detailed steps to reproduce, affected endpoints, and suggested remediation.

All validated disclosures receive prompt acknowledgement within 48 hours and credit in the subsequent release notes.
